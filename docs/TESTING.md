# 验证与维护

## 自动测试入口

`npm run check` 包含JS语法、Node内置核心测试和静态构建。测试覆盖课程时长与依赖、日期/工作日、掌握豁免、计划与实际时长分离、幂等计时、备份校验、公式注入防护和导出。

可选浏览器回归：

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
npm run dev
# 在另一个终端：
python3 tests/browser_smoke.py --url http://127.0.0.1:8787 --output artifacts
```

已安装系统Chromium时可指定 `CHROMIUM_PATH=/path/to/chromium`。浏览器测试使用全新测试上下文，不操作真实个人进度；输出桌面/深色/手机截图和JSON报告。测试脚本生成的是测试数据，不能当成用户的课程成果。

## 发版前额外检查

在真实目标浏览器检查：刷新与关闭后恢复、两窗口写入、损坏文件导入、余额计算、前置验收、任务改期、恢复快照、普通及加密备份、离线打开、键盘焦点、320–1440像素布局、低配额或隐私模式。

计时以墙钟运行，不自动推断是否在认真学习。关闭页面时提醒不保证送达；实例停机必须在云平台完成。JSON和快照恢复并不自动合并两个设备的数据。

## 课程更新

先备份用户数据；保持现有task ID稳定。任务ID变更或数据schema升级需新增明确迁移，不能把旧进度静默对应到新任务。改应用壳资源时同步更新 `sw.js` 的缓存版本；升级采用关闭旧窗口后激活，不强制在写日志时重载。
